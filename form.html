Subcommand forms




id form



	
	game title to look up in the umu-database
	


	

	






install form



	
	repack setup.exe or the directory containing it
	


	
	root directory holding installed games
	


	
	game title, used for GAMEID lookup and install folder
	


	
	folder name under games-root (default: sanitized title)
	


	
	Proton build passed to umu-run, env REPACK_PROTON (default: GE-Proton)
	


	
	force a umu GAMEID and skip the database lookup
	


	
	run the installer fully headless (/VERYSILENT instead of /SILENT)
	


	

	






list form



	
	print the raw games.json index
	


	

	






rm form



	
	install name of the game
	


	
	delete without asking
	


	

	






run form



	
	install name of the game (see: repack list)
	


	
	override the recorded main exe (remembered)
	


	

	






tricks form
